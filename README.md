
# DevFolio - Dark Developer Portfolio

A simple, responsive developer portfolio template built
with HTML, CSS, and JavaScript.

## Features

- Dark theme with green accents
- About, Skills, Projects, and Certificates sections
- Contact email link
- Responsive layout
- Automatic footer year
- No frameworks required

## Getting Started

1. Download and extract the project files.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Edit the HTML to customize your portfolio.
5. Edit style.css to change colors and spacing.

## Personalization

### Change your name
Open index.html and replace "Your Name".

### Change your email
Find "your@email.com" and replace it with your email.

### Change your skills
Edit the cards inside the Skills section.

### Add your projects
Edit the project cards and describe your own work.

### Change the colors
Open style.css and edit the variables inside :root.

## Files

- index.html: website structure and content
- style.css: design and responsive layout
- script.js: navigation behavior and footer year

## Requirements

A modern web browser. VS Code is recommended.
